# 第一轮 SINA 元件检测训练

目标：在现有 IC 数据上完成可复现的 GPU 微调，保留官方基线，并提供可交给 LabPilot 小组调用的检测入口。

范围：本轮训练 YOLO 的元件类别和边界框。OCR、语义引脚和完整拓扑不具有监督真值，不宣称经过联合训练。在线视觉模型缺少已配置供应方时不调用、不臆造结果。

环境：独立 SINA-venv，先验证 Python 3.13 + PyTorch CUDA 12.8 + RTX 5080 的实际兼容性。安装和 GPU 测试失败时先诊断。所有资产保留在本工作区。

步骤：

- [x] 审查原始 596 train / 66 val 图片和 YOLO 标注；检查完全重复图。
- [x] GPU 张量、卷积、反向传播与 torchvision NMS 实测通过；版本快照由训练入口保存。
- [x] 用官方 best.pt 在固定 960 分辨率的验证集上评估基线。
- [x] 从官方 best.pt 微调：最多 40 epochs，patience=10，batch=8，imgsz=960，seed=42，workers=0，低学习率，禁用翻转及大角度旋转。
- [x] 用相同条件评估候选，与基线比较 mAP50-95、mAP50 和关键类别召回；性能未改善时保留基线为推荐版本。
- [x] 导出训练配置、原始指标、权重指纹、标注预览图和检测 JSON，提供集成命令。

验收：训练进程正常结束且具有新权重；所有成绩来自实际评估；不将“检测准确”写成“连接正确”；没有独立测试集就明确注明泛化尚未验证。
