# 当前工作流的豆包复核

生产入口：`tools/gui_workflow.py`。默认仅本地识别，添加 `--allow-cloud` 后使用豆包Pro进行候选字段复核。

```powershell
python tools/gui_workflow.py examples/user_bjt_bias.jpg --out runs/new-pro-review --allow-cloud
```

先将根目录 `.env.example` 复制为 `.env`，填写自己的 `ARK_API_KEY`。不要提交密钥。当前生产模型由 `tools/modules/vision.py` 指定为 `doubao-seed-2-1-pro-260915`，通过官方火山方舟北京 `/api/v3/responses` 调用，不启用联网搜索。

第一阶段使用原版SINA清单提示词；第二阶段结合原图与本地框、OCR和引脚候选，按稳定ID返回编号、数值、型号与引脚语义建议。不会任意重写连接或自动确认电路。
提示词出处见 `prompts/provenance.json`；原版文字网表提示词仅保留为来源资源，不作为当前识别输出。

输出包括 `recognized.json` 草稿、原始候选、阶段事件和证据；复核阶段另保存 `sina-inventory.txt`、`review.json`。API失败时保留本地草稿。

每次使用新的输出目录。图片将发送给火山引擎并产生调用用量；未知数值/型号保持null，所有建议需要核对。
本仓库不保留旧Lite/Pro对比结果或Pro直接检测检验数据。复核模块优化任务见 [06指南](team/06-vision-review.md)，接口见 [INTERFACES](team/INTERFACES.md)。
