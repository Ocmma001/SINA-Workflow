# 豆包视觉复核接入

当前模型：`doubao-seed-2-1-pro-260915`。默认使用 SINA 原版两阶段提示词，详见 [原版提示词对齐说明](原版提示词对齐说明.md)。
接口：火山方舟北京地域 `/api/v3/responses`。

本地 `.env` 保存 `ARK_API_KEY`、`ARK_MODEL`、`ARK_RESPONSES_URL`。该文件已被忽略且不进入交付包。密钥轮换后修改本机配置即可，优先使用进程环境变量中的值。

## 使用流程

1. 使用 `tools/local_extract.py` 生成本地 `recognized.json`。
2. 使用豆包复核同一张原图与对应候选：

```powershell
.\SINA-venv\Scripts\python.exe tools\vision_review.py examples\user_bjt_bias.jpg --candidates runs\delivery-smoke-bjt\recognized.json --out runs\my-ark-review
```

每轮使用新输出目录。发送内容为原图、元件框、引脚候选和 OCR 文本，会产生 API 调用费用。不启用联网搜索，关闭思考模式，使用非流式响应以验证完整 JSON。

此前自定义复核模式（加 `--prompt-mode review`）输出单独的 `vision-review.json`：模型候选位号、参数、语义引脚、问题项和 Token 用量。不会自动修改原始 CCL 连接，不会将模型候选标记为已确认，不会直接调用 ngspice。
