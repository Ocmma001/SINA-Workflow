# 设备与任务分配（待组员配置）

当前已知用户电脑：RTX 5080 Laptop，16GB显存。round-002已经完成YOLO11m专项训练。

| 任务 | 分配建议 | 原因/条件 |
|---|---|---|
| YOLO11m 微调、多种子复验、高分辨率训练 | 优先保留给用户 | 最集中使用显存与算力；img960/batch8已有本机训练记录 |
| 引脚关键点模型训练 | 标注准备好后交用户 | 尚未建立关键点数据集，先不要开训 |
| 导线分割模型训练 | 规则方案不足、标注准备好后交用户 | 是后续候选方向，非当前工作流必需 |
| OCR 专项微调 | 只有评测证明确有必要再交用户 | 当前先做预处理与文字绑定，CPU可完成 |
| 导线 CCL、引脚吸附、文字绑定 | 普通电脑 | 主要是图像算法与规则，不依赖高级GPU |
| 豆包提示词与API对照 | 网络稳定的电脑 | 云端推理，本地高级显卡无必要 |
| 数据标注、评估、契约、集成 | 普通电脑 | 开发与小样本回归可用CPU |

“优先16GB”是基于本机已跑通配置的任务安排，不是硬性最低要求。8GB等设备可降batch/分辨率尝试，但是否能跑须实测，不能按显卡名字保证。
等待用户提供每人：操作系统、CPU、GPU完整型号及显存、内存、空闲磁盘、可用时间、是否可用API。
之后按实际人数合并聊天任务，GPU训练集中排队，组员提交数据/配置/代码，用户机器执行并回传指标与权重哈希。

参数定义参考 [Ultralytics训练文档](https://docs.ultralytics.com/modes/train/)；OCR GPU/CPU配置参考 [EasyOCR文档](https://www.jaided.ai/easyocr/documentation/)。本地工作流实际固定版本见experiments/requirements-lock.txt，最新网页示例不替代当前环境锁定。
