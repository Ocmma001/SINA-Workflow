# 数据与评估：独立优化指南

## 任务边界

负责文件：experiments/、新建 tools/dataset_audit.py 与评估脚本、tests/fixtures/。
设备建议：普通 CPU 电脑；标注优先于算力。
优先优化当前实现，任何新增模型先提供数据需求和成本。本指南是待执行任务，不是已完成的准确率承诺。

## 统一验收与交接

先读 START-HERE.md、INTERFACES.md、AGENTS.md。全流程默认离线，未知信息不补猜，旧选定权重不覆盖。
执行 `python -m unittest discover -s tools -p "test_*.py"`；使用新输出目录，保留每个失败样本。
每次只改变一个主要变量；记录 commit、数据哈希、参数/种子、耗时/显存/调用次数及逐图结果。
提交代码、必要回归测试、对照报告、坏例可视化和资源哈希；大文件与私钥不进 Git。
可直接运行的命令假设终端位于仓库根且已激活识别环境；run_stage 可用 `--help` 查看参数。

## 首轮任务（按顺序）

1. 校验596/66张图的类别、框边界、重复与近重复；按原始图来源/电路拓扑分组，避免同图裁剪落在不同集合。
2. 将66张明确登记为开发验证集；另收集不参与调参的独立测试图，建立来源与许可记录。
3. 增补 OCR 文本/框、文本到元件绑定、引脚语义、引脚所属网络的人工真值。检测框标注不能充当这些任务的真值。
4. 首批标注20–30张代表图，用于开发；两人复核争议样本。建议独立测试集再单独收集，数量据实际工作量确定。
5. 输出按图配对指标、置信区间/重采样结果、每类坏例；建立离线回放数据让其他组员无需重跑YOLO/API。

## 验收指标与常见误区

检测：P/R/F1@IoU.5/.75、mAP50-95。OCR：字符错误率、数值+单位精确匹配、绑定准确率。引脚：定位误差/角色正确率。拓扑：引脚对连通F1、整图拓扑完全正确率。端到端：器件+值+有序节点同时正确率。全部统计尝试数和失败数。
不要直接比较region整数；按图同构或元件语义引脚之间是否连通比较。
