# 实验报告模板

- 模块/负责人/日期：
- 分支/起始与结果commit：
- 假设与本次唯一主要改动：
- 数据来源/划分/清单SHA256/是否用于调参：
- 命令、环境、随机种子、模型SHA256、提示词版本：
- 尝试总数/成功数/失败数；失败类别：
- 基线与候选逐图配对结果文件：
- 模块指标（定义/分母/阈值）：
- 端到端退化检查：
- 总耗时/峰值显存/API请求数与token：
- 典型改善与退化样例：
- 独立测试是否做过；未验证内容：
- 结论：保留基线/候选待合并/需要更多数据：
- 代码修改范围、兼容性、大文件下载位置与哈希：

不要以平均成功率替代全量失败统计，不要填未经实测的数字。
