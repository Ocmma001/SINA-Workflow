# 新聊天从这里开始

目标：多人独立优化 SINA 图片识别工作流，最终交付可编辑、保留证据的电路 JSON。前端与 ngspice 不在本仓库。

## 当前已验证状态

YOLO11m 微调权重为 round-002，SHA256 见 experiments/detector-selection.json。
原始 596 张训练图、66 张验证图；类别为电阻、电容、电感、BJT、MOS、电压源、电流源、地、运放、二极管。
当前 mAP50=0.971397、mAP50-95=0.745407；固定 conf=.25/imgsz=960 时 IoU=.5 的 F1=0.951524。
这些仅为检测开发验证指标。OCR、引脚、完整拓扑尚无可靠独立测试成绩。
Pro 直接检测做过 7×66 次尝试，平均 F1=.672136，未超过 YOLO11m；保留 YOLO11m。
Pro 目前承担可选字段复核，使用原版 SINA 清单提示词 + 绑定候选 ID 的结构化复核，不输出最终仿真文件。
模块化重构不改变选定模型，不意味着准确率提升。

## 接手顺序

1. 阅读根目录 AGENTS.md 与 INTERFACES.md。
2. 按 SETUP.md 准备环境并导入单独资源包。只写数据/校验代码时不必下载 GPU 环境。
3. 创建自己的分支或独立 clone，记录起始 commit，运行现有测试。
4. 先复现基线、列出 5–10 个真实错误，再实施一个可解释的改动。
5. 按 EXPERIMENT-TEMPLATE.md 提交对照报告；本阶段没有数据支持时写“未验证”。
6. 集成负责人合并后重跑端到端回归；只有他更新选定权重和共享 JSON 接口。

## 合并条件

同一批输入、同一标注版本与同一分母；分模块指标及端到端退化都报告。
检测侧同时看 IoU .5/.75 和 mAP50-95；连接侧比较引脚网络关系，不比较任意连通区域数字。
共同验证集已经用于调优，另建来源隔离测试集后才能讨论泛化。
